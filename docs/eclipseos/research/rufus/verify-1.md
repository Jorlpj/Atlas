## Scope and handoff

- Keep the SynergyOS 1.7 row's `PasswordSet` collision; its 26300 support is declared, not a compatibility test.
- Attribute GC:203 to Z-LAG-OS. Its `FreshInstall` gate is an install-age gate, not evidence about the post-update Rufus scenario.
- For Privacy+ 0.8.3, distinguish the inspected source commit from a published release. Do not describe `AdministratorPasswordSet` as a requirement for the current user: AME's documentation distinguishes it from `PasswordSet`.
- The passwordless-user outcome needs an AME 0.8.3 GUI test or maintainer clarification. Until then, retain that narrow item as unverified. The official Wizard documentation says it prompts for credentials but does not specify whether this prompt must change the active user's password.

Admiralty grades evaluate source reliability and claim-specific credibility separately. A1 means a direct primary-source statement for the claim scope; A6 marks the absence of evidence needed to establish a released-package or runtime outcome.
