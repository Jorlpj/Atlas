# Problem catalog: debloat changes vs Store, Xbox, Windows Update and anti-cheat (26H2 focus)

Compiled 2026-11-02 by the orchestrator from read-only research passes and the EclipseOS lab, then structured by the
kind of change a playbook makes.

- **Grades** use the Admiralty system: source reliability A-F, information credibility 1-6. A1 = our own reproduced
  test or official vendor documentation.
- **"Inference"** marks an unsourced conclusion.
- **Librarians:** re-verify each row, move the sources into `sources.json`, and open register entries
  (`docs/compat-26h2/`) for the rows that touch the Atlas playbook.

Comparison of the playbooks themselves: [26h2-playbooks.md](26h2-playbooks.md).

**Evidence audit (atl-lib-2, updated 2026-11-03):** all 63 catalog findings (A01-A04, B01-B09, C01-C04, D01-D07, E01-E06, F01-F08 and G01-G25) have claim-linked Admiralty grades and source locators in merged `sources.json` (111/111 source records graded); no finding is missing graded source coverage. The 2026-11-02 pass checked lane B findings G18-G19 against `B-B2.json` and `B-B2apps.json`. The 2026-11-03 pass checked G20-G25 against ATL-2 inventories, AME logs, first-boot output and archived report. These are observations from one Hyper-V run; they establish the recorded states and errors for that run, not general causation or reproducibility. For G23, the archived report says one AME OOBE 7034 event was logged, while B-B2.json summarizes three 7034 event records (each message says the service had terminated once); the summaries disagree on the record count. G20 is only a between-lane service-state correlation. F08 was narrowed to what Microsoft says about WebView2 runtime requirements and blocked initialization; named Xbox, Widgets and launcher dependencies remain unverified. A01-A04, B01-B06 and B08 were directly checked on 2026-11-03; user reports support only the reported experience, not causation, and their limits are recorded in the rows and source notes. This pass directly checked B07, B09 and C01-C04: Atlas source confirms the Store AutoDownload write, but app staleness is an untested inference; Microsoft documents UWP startup failures when the ALL APPLICATION PACKAGES read permission is missing; Xbox sign-in reports do not establish an Atlas cause or verified fix; the cited ReviOS update-policy/Xbox link could not be located; SynergyOS issue #11 is marked fixed for next release without public cause or release verification; and old Pi-hole/Bloatbox examples are narrow and do not establish broad Windows 11 breakage. The 2026-11-03 pass directly checked D01-D07. Vendor requirements are product-specific; issue reports are bounded to the reporter, and project configuration statements do not demonstrate general failures. D01-D07 entries were narrowed to those evidence limits. E01-E06 were directly audited: the NOVA maintainer and v1.0.1 release identify a power-plan threshold fix; timer/USB/ASPM claims were bounded to source scope; the quoted Microsoft gaming URL currently redirects, so no game-specific Memory Integrity claim is treated as verified; and ReviOS #239 is a single report without a reproducible benchmark or exact build. F01-F07 were directly audited on 2026-11-03: reports were narrowed to reporter-observed symptoms, service/security causality and generality were not inferred, and issue closure was not treated as proof of a fix.

## Epic anti-cheat requirements (checked 2026-11-03)

Epic's EOS Anti-Cheat Interfaces documentation lists Secure Boot, TPM, and HVCI for its anti-cheat interface on Windows on Arm, Beta, and Insider builds. That page does not state these are requirements for every game using EAC on stable x64 Windows. Fortnite has a separate competitive rule: from 2026-02-19, PC players entering any Fortnite tournament must have Secure Boot, TPM, and IOMMU enabled. These are product- and scope-specific requirements; validate each target game's current checks instead of treating either list as a universal EAC requirement. **Grade: A1** (Epic's developer documentation and current competitive rules).

Sources: [Epic EOS Anti-Cheat Interfaces](https://dev.epicgames.com/docs/epic-online-services/trust-and-safety/anti-cheat-interfaces/anti-cheat-interfaces); [Epic Fortnite tournament requirements](https://www.fortnite.com/competitive/rules-guidelines/rules-library/new-fortnite-anti-cheat-pc-requirements-and-latest-legal-action?region=NAC).
