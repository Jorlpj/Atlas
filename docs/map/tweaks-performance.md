# Performance tweaks

The `Performance` section runs seven tasks in sequence, followed by three tasks under `performance\\system`. The Game Bar task and the paging task are present in the source tree but commented out at the call site. No general build or edition condition is shown; FTH has architecture-specific actions. (`src/playbook/Configuration/tweaks.yml:40-66`)

## Active actions

| Task | Effects and conditions |
| --- | --- |
| `config-mmcss.yml` | Sets `HKLM\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\Multimedia\\SystemProfile\\SystemResponsiveness` to DWORD `10`. (`src/playbook/Configuration/tweaks.yml:48-50`, `src/playbook/Configuration/tweaks/performance/config-mmcss.yml:1-12`) |
| `disable-auto-folder-discovery.yml` | Runs the AtlasDesktop “Disable Automatic Folder Discovery” command silently, elevated as the current user, and waits for it. | `config-automatic-maintenance.yml` | Sets the Task Scheduler Maintenance policy `WakeUp` to DWORD `0`. Two other proposed maintenance values in the file are commented out. | `disable-background-apps.yml` | Sets current-user `BackgroundAccessApplications\\GlobalUserDisabled` to DWORD `1` and `Search\\BackgroundAppGlobalToggle` to DWORD `0`. (`src/playbook/Configuration/tweaks.yml:52-54`, `src/playbook/Configuration/tweaks/performance/disable-background-apps.yml:1-13`) |

| `disable-sleep-study.yml` | Disables the SleepStudy, Kernel-Processor-Power, and UserModePowerService diagnostic event channels and disables the `Power Efficiency Diagnostics\\AnalyzeSystem` scheduled task. | `respect-power-modes-search.yml` | Sets Windows Search `SystemIndex\\RespectPowerModes` to DWORD `1`. (`src/playbook/Configuration/tweaks.yml:55-57`, `src/playbook/Configuration/tweaks/performance/respect-power-modes-search.yml:1-9`) |
| `system/optimize-ntfs.yml` | Runs `fsutil behavior set disablelastaccess 1` and `fsutil 8dot3name set 1`; the latter disables creation of 8.3 names. (`src/playbook/Configuration/tweaks.yml:59-65`, `src/playbook/Configuration/tweaks/performance/system/optimize-ntfs.yml:1-12`) |
| `system/disable-service-host-split.yml` | Iterates service keys under `HKLM\\SYSTEM\\CurrentControlSet\\Services` and sets `SvcHostSplitDisable` to DWORD `1` where a `Start` value exists, excluding names matching `Xbl` or `Xbox`. ## Present but not called

`disable-game-bar.yml` would disable Game DVR and related Game Bar settings in HKCU and HKLM, but its task call is commented out. The AtlasDesktop folder also contains a separate FSO/Game Bar enable/disable control; neither fact makes the commented task active. `system/disable-paging.yml`, which sets `DisablePagingExecutive` and `DisablePageCombining`, is also commented out; the root file says there is no evidence it helps and calls it likely placebo. ## Revert and servicing notes

AtlasDesktop includes corresponding enable controls for background apps, Sleep Study, search indexing, automatic folder discovery, and FTH. These are user-facing controls, not evidence that the playbook's upgrade-time revert restores each setting or its prior value. The inspected `revert.yml` only deletes Explorer `ThisPCPolicy` values. No direct Store, Xbox, AppX-package, or Windows Update servicing changes appear in the active performance tasks; the service-host script explicitly excludes Xbox-named services.
