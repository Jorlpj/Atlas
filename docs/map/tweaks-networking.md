# Networking tweaks

The `Networking` section runs its listed tasks in order. It invokes the Atlas network settings task, then applies three file-sharing registry values. The LLMNR task is commented out, so it is not run at this call site. No build, edition, or architecture conditions appear on the active calls. (`src/playbook/Configuration/tweaks.yml:19-36`)

## Actions

| Task | Effects and conditions |
| --- | --- |
| `atlas-network-settings.yml` | Runs `Reset Network to Atlas Default.cmd /silent` from AtlasDesktop, elevated in the current-user context and waits for completion. The script records `DefaultAtlasNetwork` state `1` and its path under `HKLM\SOFTWARE\AtlasOS\Services`; it finds PCI network adapters and, when matching adapter values exist, sets `AutoDisableGigabit`, `ApCompatMode`, `SipsEnabled`, `ReduceSpeedOnPowerDown`, and `DMACoalescing` (including `*`-prefixed variants) to string `0`. It suppresses command output and exits without the interactive reboot prompt when passed `/silent`. No OS/build guard is shown. ## Revert and servicing notes

The network-settings folder also contains a `Reset Network to Windows Default.cmd` companion. It records `DefaultAtlasNetwork` state `0` and then runs IP, IPv4, IPv6, TCP and Winsock resets, removes currently OK network devices with `pnputil`, and rescans devices. This is a broad reset, not evidence that it restores the exact prior adapter values. The Atlas-default script itself records state `1`; neither script is called as a revert by this YAML group. (`src/playbook/Executables/AtlasDesktop/9. Troubleshooting/Network/Reset Network to Atlas Default.cmd:3-5`, `src/playbook/Executables/AtlasDesktop/9. Troubleshooting/Network/Reset Network to Windows Default.cmd:3-5`, `src/playbook/Executables/AtlasDesktop/9. Troubleshooting/Network/Reset Network to Windows Default.cmd:19-21`, `src/playbook/Executables/AtlasDesktop/9. Troubleshooting/Network/Reset Network to Windows Default.cmd:27-39`, `src/playbook/Configuration/tweaks.yml:19-36`)

The upgrade-time `revert.yml` actions delete Explorer `ThisPCPolicy` values; they do not reverse these networking registry settings or run the Windows-default network reset. The active tasks alter network-adapter settings and SMB/share security and throttling behavior; they do not directly change Store, Xbox, AppX packages, or Windows Update servicing.
