# Script tweaks

The `Scripts` group calls eight tasks, with `script-power.yml` deliberately run after the `Misc` group. `script-ngen.yml` exists in the source tree but is not called from `tweaks.yml`. The listed calls have no general build or edition gate; individual options and script checks are noted below. (`src/playbook/Configuration/tweaks.yml:326-363`, `src/playbook/Configuration/tweaks/scripts/script-ngen.yml:1-8`)

## Called tasks

| Task | Actions, conditions, and effects |
| --- | --- |
| `script-file-associations.yml` | With `uninstall-edge` false, invokes `FILEASSOC.cmd` without a browser argument; when a `browser-*` option is selected, invokes it with Brave, LibreWolf, Firefox, or Chrome. The command sets URL and file-extension associations for those browsers in loaded user hives, and also writes 7-Zip associations when 7-Zip is installed. (`src/playbook/Configuration/tweaks/scripts/script-file-associations.yml:1-28`, `src/playbook/Executables/FILEASSOC.cmd:3-42,52-63`, `src/playbook/Executables/ASSOC.ps1:228-261`) |
| `script-core-isolation.yml` | Runs only with `disable-core-isolation`; calls `ConfigVBS.ps1 -DisableAllVBS`. The wrapper sets Memory Integrity, Kernel Shadow Stacks (when present), Credential Guard (when present), LSA protection, and the general VBS setting to disabled. The wrapper comments identify the latter settings as Windows 11 or 24H2-specific. (`src/playbook/Configuration/tweaks/scripts/script-core-isolation.yml:1-9`, `src/playbook/Executables/AtlasModules/Scripts/ScriptWrappers/ConfigVBS.ps1:9-38`) |
| `script-mitigations.yml` | Runs only with `mitigations-disable`; runs the AtlasDesktop “Disable All Mitigations” command elevated as the current user. That command changes system mitigation registry values, applies `bcdedit /set nx OptIn`, and specially re-enables CFG for Valorant executables. (`src/playbook/Configuration/tweaks/scripts/script-mitigations.yml:1-10`, `src/playbook/Executables/AtlasDesktop/7. Security/Mitigations/Disable All Mitigations.cmd:25-68`) |
| `script-devices.yml` | Disables the listed network adapter bindings (`ms_msclient`, `ms_server`, `ms_lldp`, `ms_lltdio`, `ms_rspndr`) and invokes `DISABLEPNP.ps1`, which disables present Plug and Play devices whose friendly names match its fixed 21-name list (including selected chipset, timer, and system devices), ignoring errors; it does not disable every present device. (`src/playbook/Configuration/tweaks/scripts/script-devices.yml:1-9`, `src/playbook/Executables/DISABLEPNP.ps1:1-27`) |
| `script-pfp.yml` | Runs `PFP.ps1` except during upgrade (`onUpgrade: false`); creates resized Atlas user and guest profile pictures in the common User Account Pictures directory. (`src/playbook/Configuration/tweaks/scripts/script-pfp.yml:1-9`, `src/playbook/Executables/PFP.ps1:1-23`) |
| `script-backup2.yml` | Calls `BACKUP.ps1` after the other Scripts tasks except `script-clientcbs.yml` (and `script-power.yml`, which runs later in Misc). It writes a `.reg` snapshot of service `Start` values, excluding services whose description matches Windows Defender; it exits without replacing an existing target file. The destination is `%windir%\AtlasModules\Other\atlasServices.reg`. (`src/playbook/Configuration/tweaks/scripts/script-backup2.yml:1-9`, `src/playbook/Executables/BACKUP.ps1:1-23`) |
| `script-clientcbs.yml` | Runs `CLIENTCBS.ps1`. The script searches Windows SystemApps for the Accounts SettingsExtensions JSON; if none is found, it reports Windows 10 as likely and exits. Otherwise it extracts feature velocity IDs, hides the Microsoft account Settings page, selects ViVeTool for ARM64 or non-ARM64, then disables the discovered IDs for the next reboot. (`src/playbook/Configuration/tweaks/scripts/script-clientcbs.yml:1-8`, `src/playbook/Executables/CLIENTCBS.ps1:9-17,39-83`) |
| `script-power.yml` | Runs last, after `Misc`. Always sets `HiberbootEnabled` to DWORD `0`; with `disable-power-saving`, calls the elevated Atlas power wrapper; with `disable-hibernation`, calls the hibernation command; unless power saving is disabled, selects the Balanced scheme. The power wrapper creates/activates an Atlas copy of Ultimate Performance, changes AC power, network-adapter, device power, and ACPI-device settings. The hibernation command runs `powercfg /h off` and hides the Explorer Hibernate option. (`src/playbook/Configuration/tweaks/scripts/script-power.yml:1-32`, `src/playbook/Configuration/tweaks.yml:347-363`, `src/playbook/Executables/AtlasModules/Scripts/ScriptWrappers/DisablePowerSaving.ps1:28-60,62-110`, `src/playbook/Executables/AtlasDesktop/3. General Configuration/Hibernation/Disable Hibernation (default).cmd:17-22`) |

## Revert and servicing scope

The upgrade-time `revert.yml` actions delete Explorer `ThisPCPolicy` values; they do not restore the file associations, VBS or mitigation settings, device states, profile images, service snapshot, or power settings listed here. (`src/playbook/Configuration/atlas/revert.yml:1-36`) The inspected task files and called scripts do not show Store, Xbox, AppX package, or Windows Update servicing operations. File associations, network bindings, devices, VBS, mitigations, and power settings can affect user capabilities or security, but the cited actions do not remove Store/Xbox packages. (`src/playbook/Configuration/tweaks/scripts/script-file-associations.yml:1-28`, `src/playbook/Configuration/tweaks/scripts/script-core-isolation.yml:1-9`, `src/playbook/Configuration/tweaks/scripts/script-mitigations.yml:1-10`, `src/playbook/Configuration/tweaks/scripts/script-devices.yml:1-9`, `src/playbook/Configuration/tweaks/scripts/script-power.yml:1-32`)
