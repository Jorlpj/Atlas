# Privacy tweak group

`Configuration/tweaks.yml` runs the privacy group after Performance and before QoL. It calls the main files first, followed by the `apps`, `advertising`, `cloud` and `telemetry` subgroups. The root lists these tasks directly and declares no option or build gate for the group. (`src/playbook/Configuration/tweaks.yml:71-131`)

## Configured changes

The actions below describe the YAML and script settings. Unless noted, each task is unconditional at the point it is called; the source files declare no edition or architecture condition.

- **Permissions, media and device features:** `config-app-permissions.yml` sets the machine defaults for app diagnostics, location and account-information consent to `Deny` (`src/playbook/Configuration/tweaks/privacy/config-app-permissions.yml:1-19`). `config-windows-media-player.yml` disables online DRM access, marks the privacy statement accepted and turns off usage tracking (`src/playbook/Configuration/tweaks/privacy/config-windows-media-player.yml:1-26`). `disable-activity-feed.yml` disables Activity Feed by policy (`src/playbook/Configuration/tweaks/privacy/disable-activity-feed.yml:1-9`); `disable-lockscreen-camera.yml` blocks camera use on the lock screen (`src/playbook/Configuration/tweaks/privacy/disable-lockscreen-camera.yml:1-9`); `disable-device-monitoring.yml` disables Device Health Attestation monitoring/reporting (`src/playbook/Configuration/tweaks/privacy/disable-device-monitoring.yml:1-9`).
- **Usage, compatibility and diagnostics:** `disable-app-launch-tracking.yml` disables Start app-use tracking (`src/playbook/Configuration/tweaks/privacy/disable-app-launch-tracking.yml:1-10`); `disable-user-tracking.yml` disables the Start menu's most-frequently-used app list (`src/playbook/Configuration/tweaks/privacy/disable-user-tracking.yml:1-9`). `disable-experimentation.yml` turns off the configured experimentation policy (`src/playbook/Configuration/tweaks/privacy/disable-experimentation.yml:1-9`). `disable-pca.yml` disables Program Compatibility Assistant, its engine/inventory and related telemetry (`src/playbook/Configuration/tweaks/privacy/disable-pca.yml:1-34`); `disable-perf-track.yml` disables the configured WDI scenario execution setting (`src/playbook/Configuration/tweaks/privacy/disable-perf-track.yml:1-10`); `disable-rsop-logging.yml` disables Resultant Set of Policy logging (`src/playbook/Configuration/tweaks/privacy/disable-rsop-logging.yml:1-9`).
- **Speech, input and reports:** `disable-online-speech-recognition.yml` sets the current user's online-speech consent to not accepted; its machine policy alternative is commented out (`src/playbook/Configuration/tweaks/privacy/disable-online-speech-recognition.yml:1-17`). `disable-speech-auto-updates.yml` disables speech-model updates (`src/playbook/Configuration/tweaks/privacy/disable-speech-auto-updates.yml:1-9`). `telemetry/disable-input-telemetry.yml` turns off configured ink, text, handwriting and typing collection/report settings (`src/playbook/Configuration/tweaks/privacy/telemetry/disable-input-telemetry.yml:1-57`). `disable-win-error-reporting.yml` sets user and machine error-reporting, UI and logging policies to disabled (`src/playbook/Configuration/tweaks/privacy/disable-win-error-reporting.yml:1-61`).
- **Activities, personalization and account behavior:** `disable-privacy-experience.yml` suppresses the OOBE privacy experience (`src/playbook/Configuration/tweaks/privacy/disable-privacy-experience.yml:1-9`); `disable-tailored-experiences.yml` disables tailored experiences based on diagnostic data (`src/playbook/Configuration/tweaks/privacy/disable-tailored-experiences.yml:1-15`); `disallow-user-activity-upload.yml` disables upload and publishing of user activities (`src/playbook/Configuration/tweaks/privacy/disallow-user-activity-upload.yml:1-14`). `disallow-ms-accounts.yml` prevents adding Microsoft accounts as Windows user accounts (`src/playbook/Configuration/tweaks/privacy/disallow-ms-accounts.yml:1-9`). `disable-web-lang-list-access.yml` opts out of websites accessing the user's language list (`src/playbook/Configuration/tweaks/privacy/disable-web-lang-list-access.yml:1-10`).
- **Search:** `search-settings.yml` disables configured Bing/cloud/web search and location use, search-history settings and suggestions, and sets the taskbar search display to icon. Its `!powerShell` fallback applies only during OOBE; the registry settings preceding it have no such condition (`src/playbook/Configuration/tweaks/privacy/search-settings.yml:1-84`).
- **Application settings:** `apps/disable-nvidia-telemetry.yml` opts out the current user in NVIDIA Control Panel (`src/playbook/Configuration/tweaks/privacy/apps/disable-nvidia-telemetry.yml:1-9`). `apps/disable-office-telemetry.yml` sets Office customer-data, telemetry and CEIP values (`src/playbook/Configuration/tweaks/privacy/apps/disable-office-telemetry.yml:1-22`).
- **Advertising and sync:** `advertising/disable-advertising-info.yml` disables the current user's Advertising ID and sets the machine policy (`src/playbook/Configuration/tweaks/privacy/advertising/disable-advertising-info.yml:1-15`). `advertising/disable-sync-provider-notifs.yml` disables Explorer sync-provider notifications (`src/playbook/Configuration/tweaks/privacy/advertising/disable-sync-provider-notifs.yml:1-9`). `cloud/disable-setting-sync.yml` disables configured machine and per-user settings-sync values for personalization, browser settings, credentials, accessibility and Windows (`src/playbook/Configuration/tweaks/privacy/cloud/disable-setting-sync.yml:1-61`). `cloud/disable-suggest-ways-to-finish-setup.yml` disables the configured setup suggestion (`src/playbook/Configuration/tweaks/privacy/cloud/disable-suggest-ways-to-finish-setup.yml:1-9`); `cloud/disallow-message-cloud-sync.yml` disables message-service cloud sync (`src/playbook/Configuration/tweaks/privacy/cloud/disallow-message-cloud-sync.yml:1-9`).
- **Telemetry:** `telemetry/disable-activation-telemetry.yml` disables the configured KMS client ticket-generation setting (`src/playbook/Configuration/tweaks/privacy/telemetry/disable-activation-telemetry.yml:1-10`); `telemetry/disable-ceip.yml` disables CEIP for App-V and SQM Client (`src/playbook/Configuration/tweaks/privacy/telemetry/disable-ceip.yml:1-14`); `telemetry/disable-diagnostic-tracing.yml` disables the configured performance diagnostic tracing value (`src/playbook/Configuration/tweaks/privacy/telemetry/disable-diagnostic-tracing.yml:1-9`). `telemetry/disable-dotnet-cli-telemetry.yml` sets `DOTNET_CLI_TELEMETRY_OPTOUT=1` with `setx` (`src/playbook/Configuration/tweaks/privacy/telemetry/disable-dotnet-cli-telemetry.yml:1-6`). `telemetry/disallow-data-collection.yml` stops DiagTrack, writes data-collection and event-transcript values, disables its WMI autologger, and deletes matching DiagTrack ETL logs under the AutoLogger and ShutdownLogger directories (`src/playbook/Configuration/tweaks/privacy/telemetry/disallow-data-collection.yml:1-57`).
- **Recall:** `disable-recall-snap.yml` is explicitly gated at build `>=22000` and calls the bundled AtlasDesktop default-disable script as the current elevated user (`src/playbook/Configuration/tweaks/privacy/disable-recall-snap.yml:1-10`). That script sets Atlas' Recall state to `0` and writes the Windows AI `DisableAIDataAnalysis=1` policy (`src/playbook/Executables/AtlasDesktop/3. General Configuration/AI Features/Recall/Disable Recall Support (default).cmd:1-24`).

## Restore and servicing scope

The privacy tasks configure registry values, one environment variable, stop DiagTrack, remove diagnostic ETL logs, and update Atlas/Windows Recall settings. The matching `revert.yml` is an upgrade-time cleanup for named legacy Explorer `ThisPCPolicy` values only; it does not restore these privacy settings, restart DiagTrack, or recover deleted logs (`src/playbook/Configuration/atlas/revert.yml:1-36`). These files declare no Store or Xbox package action, Windows Update operation, AppX servicing, service startup-type change, or privacy-setting rollback. The `disallow-ms-accounts` policy does affect account choice, and the search tasks disable selected online-search features; neither is an AppX or update-servicing action (`src/playbook/Configuration/tweaks/privacy/disallow-ms-accounts.yml:1-9`; `src/playbook/Configuration/tweaks/privacy/search-settings.yml:1-84`).
