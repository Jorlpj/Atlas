# Store, Xbox, AppX and Windows Update touchpoints

This page groups configured and user-launched Atlas actions that directly change Store, Xbox/Game Bar, AppX packages or servicing, or Windows Update settings. “Sensitive” means the action names or changes one of these surfaces; it does not establish a compatibility outcome. See [AppX](../appx.md), [components](../components.md), [services](../services.md), [QoL tweaks](../tweaks-qol.md), [debloat tweaks](../tweaks-debloat.md), [default settings](../default.md), [AtlasDesktop](../atlasdesktop.md), [Atlas modules](../atlasmodules.md), and [playbook options](../playbook-conf.md) for the area maps.

## Scope and setup gates

Atlas 0.5.0 lists build 26100 and 26200 in its supported-build block; 26300 is not listed. Setup declares `NoPendingUpdates` and `UCPDDisabled` requirements, and the Windows Update choice defaults to `auto-updates-disable`. These declarations do not explain the gate implementation or prove an update-service sequence. (`src/playbook/playbook.conf:14-29,85-98`; [playbook.conf map](../playbook-conf.md))

The actions below are grouped by the map area that defines them. Unless noted, no action-specific build or edition guard appears in the cited task. Do not infer that a map entry is automatically run merely because its files are installed: AtlasDesktop controls are user-launched; the configured task sequence and option gates are identified separately.

## Revert boundary and interpretation

The upgrade `revert.yml` is not a general undo: it deletes legacy Explorer `ThisPCPolicy` values and contains no Store, Xbox, AppX, service, or Windows Update restoration. Where an explicit AtlasDesktop pair exists, that is a separate user-launched control and may not restore the original system state. Check each cited script before treating it as a reversible action. (`src/playbook/Configuration/atlas/revert.yml:1-36`; [revert map](../revert.md); [AtlasDesktop map](../atlasdesktop.md))

This inventory reports configured operations, options and declared restore paths. It does not establish whether any one action causes a Store/Xbox failure or predicts runtime compatibility on a Windows build.
