# Quality-of-life tweaks

`Configuration/tweaks.yml` runs the QoL group after Performance and Privacy. It invokes the root QoL tasks, then the appearance, Windows Update, accessibility, taskbar, Explorer, context-menu, security, shell, startup/shutdown and system subgroups. Many calls have task-specific option or build gates (mostly `>=22000`); check each task for its exact condition. The Explorer `disable-folders-this-pc` call and the startup/shutdown `force-end-shutdown-apps` and `enable-verbose-messages` calls are commented out. (`src/playbook/Configuration/tweaks.yml:136-295`)

## Configured changes

- **Boot, display, input and sound:** `bcdedit-tweaks.yml` sets the boot menu timeout to 10 seconds and selects the legacy boot menu (`src/playbook/Configuration/tweaks/qol/bcdedit-tweaks.yml:1-14`). `visual-effects.yml` configures Windows visual-effects values for responsiveness; `best-wallpaper-quality.yml` disables wallpaper compression (`src/playbook/Configuration/tweaks/qol/visual-effects.yml:1-33`; `src/playbook/Configuration/tweaks/qol/best-wallpaper-quality.yml:1-9`). Mouse acceleration is disabled for the current user; touch keyboard and visual feedback, USB issue notifications, sound ducking, and visibility of disabled sound devices are configured through their registry tasks (`src/playbook/Configuration/tweaks/qol/disable-mouse-accel.yml:1-25`; `src/playbook/Configuration/tweaks/qol/disable-touch-keyboard-features.yml:1-19`; `src/playbook/Configuration/tweaks/qol/disable-touch-visual-feedback.yml:1-18`; `src/playbook/Configuration/tweaks/qol/disable-usb-issues-notifications.yml:1-18`; `src/playbook/Configuration/tweaks/qol/do-not-reduce-sounds.yml:1-9`; `src/playbook/Configuration/tweaks/qol/hide-disabled-disconnected-sounds.yml:1-18`). Dynamic Lighting is set off for the current user only on builds `>=22000` (`src/playbook/Configuration/tweaks/qol/disable-dynamic-lighting.yml:1-9`).
- **Start, accessibility and settings:** the tasks configure Start behavior, Ink Workspace, tips and Settings suggestions/banner; turn off spelling suggestions and Windows Feedback; and adjust accessibility shortcuts, warning sounds and Control Panel reading options (`src/playbook/Configuration/tweaks/qol/config-start-menu.yml:1-34`; `src/playbook/Configuration/tweaks/qol/config-windows-ink-workspace.yml:1-9`; `src/playbook/Configuration/tweaks/qol/disable-settings-tips.yml:1-14`; `src/playbook/Configuration/tweaks/qol/disable-tips.yml:1-10`; `src/playbook/Configuration/tweaks/qol/disable-win11-settings-banner.yml:1-9`; `src/playbook/Configuration/tweaks/qol/disable-spell-checking.yml:1-32`; `src/playbook/Configuration/tweaks/qol/disable-windows-feedback.yml:1-20`; `src/playbook/Configuration/tweaks/qol/ease-of-access/disable-annoying-features-shortcuts.yml:1-33`; `src/playbook/Configuration/tweaks/qol/ease-of-access/disable-making-touch-easier.yml:1-9`; `src/playbook/Configuration/tweaks/qol/ease-of-access/disable-warning-sounds.yml:1-26`; `src/playbook/Configuration/tweaks/qol/ease-of-access/disable-always-read-section.yml:1-18`). `show-all-tasks-control-panel.yml` adds the All Tasks Control Panel shell entry. - **Explorer and file handling:** active tasks set Explorer to open to This PC, use compact mode, show hidden/system files and extensions, hide recent/frequent items, extend the icon cache, shorten hover delay, increase the context-menu selection limit, enable long paths, change search behavior, and alter the navigation pane. - **Windows Update and Store:** the Store task writes `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\WindowsStore\WindowsUpdate\AutoDownload=2` (`REG_DWORD`), disabling automatic app updates in Store (`src/playbook/Configuration/tweaks/qol/disable-store-auto-updates.yml:1-9`). This changes Store update behavior; it does not remove Store or Xbox packages. The Windows Update sub-group disables update nagging, Insider enrollment, MSRT telemetry and Delivery Optimization; targets feature updates; and sets automatic restart policy values (`src/playbook/Configuration/tweaks.yml:180-188`). The automatic-update task invokes the AtlasDesktop disable script only when `auto-updates-disable` is selected and creates `HKLM\SOFTWARE\Microsoft\WindowsUpdate\Orchestrator\UScheduler_Oobe\DevHomeUpdate` and `...\OutlookUpdate` keys, then sets `workCompleted=1` under the corresponding `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\WindowsUpdate\Orchestrator\UScheduler` task keys (`src/playbook/Configuration/tweaks/qol/windows-update/disable-auto-updates.yml:1-17`). Feature-update targeting uses registry and PowerShell actions; inspect the chosen branch and current product version before interpreting the target value (`src/playbook/Configuration/tweaks/qol/windows-update/disable-feature-updates.yml:1-14`). Other update policies are in the cited task files (`src/playbook/Configuration/tweaks/qol/windows-update/disable-nagging.yml:1-9`; `src/playbook/Configuration/tweaks/qol/windows-update/disable-insider.yml:1-19`; `src/playbook/Configuration/tweaks/qol/windows-update/disable-msrt-telemetry.yml:1-8`; `src/playbook/Configuration/tweaks/qol/windows-update/disable-delivery-optimization.yml:1-9`; `src/playbook/Configuration/tweaks/qol/windows-update/disable-auto-reboot.yml:1-10`).

## Revert and servicing scope

These tasks primarily write registry values/keys, change BCD settings, run PowerShell or command scripts, and create shell associations. The matching `Configuration/atlas/revert.yml` removes a set of named legacy Explorer `ThisPCPolicy` values, but does not restore the QoL settings, reverse BCD changes, or undo the Store/Windows Update policies described here (`src/playbook/Configuration/atlas/revert.yml:1-36`). Automatic Store app archival and automatic Store app updates are distinct controls: the former is invoked by a script, the latter writes `AutoDownload=2`; neither task removes AppX packages (`src/playbook/Configuration/tweaks/qol/disable-auto-app-archival.yml:1-9`; `src/playbook/Configuration/tweaks/qol/disable-store-auto-updates.yml:1-9`). These QoL calls do not directly service AppX packages or Xbox, though they do alter Store app update/archival behavior and several Windows Update policies.
