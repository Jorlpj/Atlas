# Miscellaneous tweaks

The `Misc` section runs in the listed order after the other tweak groups. It calls nine tasks and then runs `script-power.yml` between the Music and notifications tasks. No build or edition condition is shown at this call site; the ARM64 file deletion has an explicit `cpuArch` condition. (`src/playbook/Configuration/tweaks.yml:347-365`, `src/playbook/Configuration/tweaks/misc/delete-windows-specific-files.yml:5-11`)

## Actions

| Task | Effects and conditions |
| --- | --- |
| `config-time.yml` | Starts `w32time` (ignoring start errors), configures four `pool.ntp.org` peers as manual sources, updates the service configuration and requests resynchronization (ignoring resync errors). No build or architecture guard is shown. (`src/playbook/Configuration/tweaks/misc/config-time.yml:5-9`) |
| `delete-windows-specific-files.yml` | On ARM64, recursively deletes `*Open-Shell*` under the Windows `AtlasDesktop\4. Interface Tweaks\Start Menu` directory. Despite the title/comment, this file's action is explicitly guarded by `cpuArch: Arm64`; it does not show a Windows-version condition. (`src/playbook/Configuration/tweaks/misc/delete-windows-specific-files.yml:5-11`) |
| `rebuild-perf-counters.yml` | Runs `lodctr /r` twice, then `winmgmt /resyncperf`; no task condition is shown. (`src/playbook/Configuration/tweaks/misc/rebuild-perf-counters.yml:5-8`) |
| `make-measuresleep-admin.yml` | Sets the `RUNASADMIN` compatibility layer for the `! MeasureSleep.exe` file under AtlasDesktop, using `HKLM\Software\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\Layers`. (`src/playbook/Configuration/tweaks/misc/make-measuresleep-admin.yml:5-10`) |
| `create-shortcuts.yml` | Runs `SHORTCUTS.ps1` from the executable directory. The script creates an Atlas folder shortcut for the default user, copies it to existing user desktop folders and the common Start Menu, and creates a services-restore shortcut in AtlasDesktop. (`src/playbook/Configuration/tweaks/misc/create-shortcuts.yml:5-8`, `src/playbook/Executables/SHORTCUTS.ps1:1-27`) |
| `add-newUser-script.yml` | Writes a `RunScript` value under the mounted default user's `HKU\AME_UserHive_Default\...\RunOnce`, invoking `Windows\AtlasModules\Scripts\newUsers.ps1` at next logon. (`src/playbook/Configuration/tweaks/misc/add-newUser-script.yml:5-10`) |
| `add-music-videos-to-home.yml` | In the current user context, pins the Videos and Music known folders into Explorer Home only when each path is not already pinned. (`src/playbook/Configuration/tweaks/misc/add-music-videos-to-home.yml:5-18`) |
| `enable-notifications.yml` | Runs `ENABLENOTIFS.cmd` elevated. The script removes notification-blocking policy values, sets notification consent/sound/toast registry values, unhides the Notifications and Privacy-Notifications Settings pages, and configures `WpnUserService` and `WpnService` to run. (`src/playbook/Configuration/tweaks/misc/enable-notifications.yml:5-9`, `src/playbook/Executables/ENABLENOTIFS.cmd:3-20`) |
| `config-oem-information.yml` | Sets the boot entry description to an AtlasOS Windows 10/11 label based on build number (22000 threshold) and an `AtlasVersionUndefined` placeholder; sets `OEMInformation\Model`, `RegisteredOrganization`, `Manufacturer`, `SupportURL`, and `SupportPhone`. The file does not show a build guard around the action. (`src/playbook/Configuration/tweaks/misc/config-oem-information.yml:5-33`) |

Two YAML files are present in the `misc` directory but are not called by this section: `enable-winre.yml` runs elevated `reagentc /enable`, and `remove-efi-drive-letter.yml` removes the first EFI system partition's drive-letter access path when one exists; neither appears among the calls at the root. (`src/playbook/Configuration/tweaks.yml:355-365`, `src/playbook/Configuration/tweaks/misc/enable-winre.yml:5-9`, `src/playbook/Configuration/tweaks/misc/remove-efi-drive-letter.yml:5-31`)

## Servicing and revert notes

These calls do not directly remove Store or Xbox packages or modify AppX servicing. The misc files configure Windows Time, performance counters, Explorer shortcuts/pins, notification settings/services, a RunOnce script, boot description, OEM information and (on ARM64) AtlasDesktop files; none identifies a Windows Update operation. (`src/playbook/Configuration/tweaks.yml:355-365`, `src/playbook/Configuration/tweaks/misc/config-time.yml:5-9`, `src/playbook/Configuration/tweaks/misc/enable-notifications.yml:5-9`, `src/playbook/Configuration/tweaks/misc/config-oem-information.yml:5-33`)

`ENABLENOTIFS.cmd` describes its registry operations as reverting earlier changes and restores several notification values, pages and service startup settings. The upgrade-time `revert.yml` itself only deletes Explorer `ThisPCPolicy` values; it does not reverse this group's time-server settings, compatibility flag, shortcuts/pins, RunOnce value, OEM/boot values, ARM64 file deletion, or performance-counter rebuild. (`src/playbook/Executables/ENABLENOTIFS.cmd:3-20`, `src/playbook/Configuration/atlas/revert.yml:1-36`, `src/playbook/Configuration/tweaks/misc/config-time.yml:5-9`, `src/playbook/Configuration/tweaks/misc/make-measuresleep-admin.yml:5-10`, `src/playbook/Configuration/tweaks/misc/create-shortcuts.yml:5-8`, `src/playbook/Configuration/tweaks/misc/add-newUser-script.yml:5-10`, `src/playbook/Configuration/tweaks/misc/add-music-videos-to-home.yml:5-18`, `src/playbook/Configuration/tweaks/misc/config-oem-information.yml:5-33`, `src/playbook/Configuration/tweaks/misc/delete-windows-specific-files.yml:5-11`, `src/playbook/Configuration/tweaks/misc/rebuild-perf-counters.yml:5-8`)
